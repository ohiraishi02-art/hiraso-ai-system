# 会話中の重要情報をメモリに保存する

会話中の重要な情報をメモリファイルに保存するスキル。

## 実行手順

1. **情報の抽出**
   会話から以下のカテゴリに該当する情報を抽出する：
   - **意思決定**: 何かを決めた理由・背景
   - **方針・好み**: ユーザーの個人的なポリシー、仕事のスタイル、好み
   - **事実情報**: 取引先情報、数値データ、期日
   - **アイデア**: 将来検討したいこと、思いつき
   - **人間関係**: 重要な人物とその関係性
   - **プライベート**: 個人的な予定・目標・嗜好

2. **カテゴリ分類と保存先の決定**
   `00_context/memories/` 配下に以下のファイル構成で保存する：
   - `decisions.md` — 意思決定ログ
   - `preferences.md` — 方針・好み・スタイル
   - `facts.md` — 事実情報・データ
   - `ideas.md` — アイデア・検討事項
   - `people.md` — 人間関係メモ
   - `personal.md` — プライベート情報

3. **保存フォーマット**
   ```markdown
   ### YYYY-MM-DD: [タイトル]
   - 内容: ...
   - 背景/文脈: ...
   - 関連: ...
   ```

4. **保存の実行**
   - 該当ファイルが存在しない場合は新規作成
   - 既存ファイルがある場合は末尾に追記
   - 日付と文脈を必ず記載

5. **報告**
   - 保存した内容をユーザーに提示し確認を取る
   - 修正があれば反映する
