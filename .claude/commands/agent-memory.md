# /agent-memory — メモリ保存

会話中の重要な情報をメモリファイルに保存するスキル。

## 実行手順

1. **保存すべき情報を抽出**
   以下の種類の情報を対象とする：
   - 意思決定とその理由（「〜することに決めた。理由は〜」）
   - ユーザーの好み・方針（「〜のスタイルで書いてほしい」「〜は避けたい」）
   - 事実情報・データ（数値、日付、固有名詞）
   - 重要なコンテキスト（クライアント情報、プロジェクトの前提）

2. **カテゴリに分類**
   | カテゴリ | 保存先ファイル |
   |---------|-------------|
   | 意思決定ログ | `00_context/memories/decisions.md` |
   | 個人の好み・方針 | `00_context/memories/preferences.md` |
   | 事業・クライアント情報 | `00_context/memories/business.md` |
   | プロジェクト情報 | `00_context/memories/projects.md` |

3. **ファイルに追記**
   以下のフォーマットで追記する：
   ```
   ## {YYYY-MM-DD}
   - {保存内容}
   ```

4. **保存内容を報告**
   何を・どこに保存したかをユーザーに報告する。

## 注意事項
- 機密情報（APIキー、パスワード、財務詳細）は保存しない
- 個人情報（第三者の情報）は最小限にとどめる
