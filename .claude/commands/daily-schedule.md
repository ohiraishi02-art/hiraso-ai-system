# /daily-schedule — 朝の工程表生成

毎朝の工程表を作成するスキル。以下の手順で実行する。

## 実行手順

1. **今日の日付を確認**
   - 本日の日付（YYYY-MM-DD）を取得する

2. **カレンダー確認**（Google Calendar連携済みの場合）
   - 今日のすべての予定を取得する
   - 時間・場所・参加者を整理する

3. **タスク確認**（GitHub連携済みの場合）
   - 進行中・未着手のIssueを取得する
   - 優先度ラベルで並び替える

4. **DAILY.mdの確認**
   - `/Users/osamuhiraishi/AIエージェント/DAILY.md` を読み込む
   - 昨日の未完了タスクを確認する

5. **タスク分類**
   以下の2軸でタスクを分類する：
   - 緊急度 × 重要度（アイゼンハワーマトリクス）
   - 認知負荷（重い作業 / 軽い作業）

6. **工程表生成**
   - 15分刻みのタイムブロックで工程表を作成する
   - 認知負荷の高い作業を午前中に配置する
   - バッファ時間（15〜30分）を適切に挟む

7. **DAILY.mdに書き込む**
   今日の日付で DAILY.md を更新する。フォーマット：

   ```
   ## {YYYY-MM-DD}

   ### 今日の工程表
   | 時間 | タスク | 備考 |
   |------|--------|------|
   | 09:00 | ... | |
   | 09:30 | ... | |

   ### 優先タスク
   - [ ] ...
   ```

8. **報告**
   工程表をチャットに表示して完了を報告する。

## 注意事項
- カレンダー・GitHubが未連携の場合は、ユーザーに確認してから進める
- 詰め込みすぎず、1日6〜8時間の実稼働時間を想定する
