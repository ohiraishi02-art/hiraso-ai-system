# /trend-check — トレンド情報収集

Web検索・SNSからトレンド情報を収集し、分類して保存するスキル。

## 実行手順

1. **収集テーマを確認**
   - ユーザーが指定したテーマがあればそれを使用
   - 指定がない場合は CLAUDE.md の事業概要に基づいて関連テーマを自動設定

2. **情報収集**
   以下のカテゴリで情報を収集する：
   - 業界ニュース・最新動向
   - 技術・サービスの新情報
   - 競合・市場の動き
   - バイラルコンテンツ・話題のテーマ

3. **情報の整理・分類**
   収集した情報を以下で評価する：
   - 重要度（高・中・低）
   - 自分のビジネスへの関連性
   - コンテンツネタとしての活用可能性

4. **レポート生成**
   以下のフォーマットでレポートを作成する：
   ```markdown
   # トレンドレポート {YYYY-MM-DD}

   ## 注目情報
   ### [タイトル]
   - 概要：
   - 重要度：高/中/低
   - コンテンツ活用：可能/不可

   ## 今週のキーワード
   -

   ## コンテンツネタ候補
   -
   ```

5. **ファイルに保存**
   `output/trends/trend-{YYYY-MM-DD}.md` に保存する。

6. **サマリーを報告**
   主要な3〜5件をチャットに表示して完了を報告する。
