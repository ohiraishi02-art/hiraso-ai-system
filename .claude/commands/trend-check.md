# トレンド情報を収集・分類する

指定テーマのトレンド情報を収集・分類するスキル。

## 実行手順

1. **テーマの確認**
   - ユーザーから調査テーマを受け取る
   - テーマが曖昧な場合は具体化のための質問を行う
   - 例：「AI トレンド」→「生成AI活用の最新ビジネスユースケース」

2. **情報収集**
   Web検索を使って以下の観点で情報を収集する：
   - 最新ニュース・プレスリリース
   - 業界レポート・分析記事
   - 技術動向・リリース情報
   - SNSでの話題・議論

3. **情報の分類**
   収集した情報を以下のカテゴリで整理する：
   - **市場動向**: 市場規模、成長率、予測
   - **技術トレンド**: 新技術、アップデート、技術比較
   - **競合動向**: 競合の動き、新サービス、戦略
   - **ユースケース**: 活用事例、成功事例、失敗事例
   - **規制・政策**: 法規制、ガイドライン、業界基準

4. **分析と示唆**
   - 各カテゴリの要点をまとめる
   - ユーザーの事業（AIツール開発・販売）への影響・示唆を提示
   - 「So What?」（だから何をすべきか）を必ず含める

5. **出力**
   - `output/trends/YYYY-MM-DD_[テーマ].md` に保存
   - 重要度の高い情報はサマリーとしてユーザーに即時報告

## 出力フォーマット

```markdown
# トレンドレポート: [テーマ]
**調査日**: YYYY-MM-DD

## サマリー
（3〜5行で全体像を要約）

## 市場動向
- ...

## 技術トレンド
- ...

## 競合動向
- ...

## ユースケース
- ...

## 事業への示唆
（ユーザーの事業に対するインサイト・提案）

## ソース
- [タイトル](URL)
```
