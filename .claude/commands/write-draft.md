# /write-draft — コンテンツ下書き生成

テーマを受け取り、記事・SNS投稿の下書きを生成するスキル。

## 実行手順

1. **テーマ・要件の確認**
   以下を確認する（指定がない場合はデフォルト値を使用）：
   - テーマ（必須）
   - 媒体：ブログ / note / LinkedIn / X(Twitter) / その他
   - 文字数：短め（500字以内） / 普通（1000〜2000字） / 長め（3000字以上）
   - トーン：論理的・専門的 / 親しみやすい・カジュアル / 熱量高め

2. **コンテキスト収集**
   - `CLAUDE.md` から事業概要・ターゲット読者情報を参照
   - `05_learning/` から関連するインプット・参考資料を確認
   - `output/trends/` から関連するトレンド情報を確認

3. **構成案の作成**
   - タイトル案を3パターン生成
   - 記事の構成（見出し）を作成
   - ユーザーに確認を取る

4. **下書き執筆**
   構成が承認されたら本文を執筆する：
   - 読者の課題・共感から始める
   - 具体例・データで根拠を示す
   - 行動を促すCTAで締める

5. **ファイルに保存**
   `output/articles/draft-{YYYY-MM-DD}-{テーマ}.md` に保存する。

6. **完了報告**
   下書きのファイルパスと文字数を報告する。

## 注意事項
- 著作権のある文章は引用しない
- ファクトチェックが必要な数値・データは必ずユーザーに確認を求める
- 「これが正確な情報です」と断言せず、必要に応じて確認を促す
