# 記事の下書きを生成する

テーマを受け取り、記事の下書きを生成するスキル。

## 実行手順

1. **テーマ・要件の確認**
   ユーザーに以下を確認する：
   - 記事のテーマ・タイトル案
   - 想定読者（ターゲット）
   - 記事の目的（認知獲得、リード獲得、ブランディング等）
   - 希望の文字数・トーン
   - 公開先（ブログ、note、SNS等）

2. **構成案の作成**
   まず構成案（アウトライン）を作成し、ユーザーに確認を取る：
   - 導入（フック）
   - 本文（3〜5セクション）
   - 結論・CTA
   - 各セクションの要点を箇条書きで提示

3. **リサーチ**（必要な場合）
   - Web検索で最新情報・データを収集
   - 関連する自社コンテンツ・過去記事がないか `output/articles/` を確認
   - `output/trends/` のトレンドレポートも参照

4. **下書き執筆**
   - 構成案に基づいて本文を執筆
   - 専門用語には簡潔な説明を添える
   - 具体例・データを盛り込む
   - 読みやすさを重視（短い段落、見出しの活用）

5. **出力**
   - `output/articles/YYYY-MM-DD_[タイトル].md` に保存
   - ユーザーに下書きを提示し、フィードバックを受ける
   - 修正があれば反映

## 出力フォーマット

```markdown
# [タイトル]

> **想定読者**: ...
> **文字数**: 約X,XXX文字
> **公開先**: ...

---

## 導入

（本文）

## セクション1: [見出し]

（本文）

## セクション2: [見出し]

（本文）

...

## まとめ

（本文・CTA）

---
**メタ情報**
- キーワード: ...
- 公開予定日: ...
```
