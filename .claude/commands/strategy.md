# /strategy — 戦略分析チーム起動

複数エージェントによる戦略分析を実行するスキル。

## チーム構成

| エージェント | 役割 | 使用ファイル |
|------------|------|------------|
| 問いの設計 | 分析すべき問いを構造化 | `.claude/agents/question-designer.md` |
| 市場調査 | 市場規模・トレンド・競合を調査 | `.claude/agents/market-researcher.md` |
| 戦略設計 | 調査結果を統合し戦略オプションを設計 | `.claude/agents/strategy-designer.md` |
| 批判的レビュー | 戦略の弱点・リスクを指摘 | `.claude/agents/critical-reviewer.md` |

## ワークフロー

```
ユーザー入力（テーマ）
    ↓
[問いの設計エージェント] → リサーチアジェンダ
    ↓
[市場調査エージェント] → 調査結果
    ↓
[戦略設計エージェント] → 戦略オプション・推奨案
    ↓
[批判的レビュアー] → リスク・改善点
    ↓
最終レポート生成
```

## 実行手順

1. **テーマを受け取る**
   - ユーザーから分析したい戦略テーマを確認する

2. **エージェントを順次実行**
   a. 問いの設計エージェントを実行 → リサーチアジェンダを取得
   b. 市場調査エージェントを実行 → 調査結果を取得
   c. 戦略設計エージェントを実行 → 戦略オプションを取得
   d. 批判的レビュアーを実行 → リスク評価を取得

3. **最終レポートを生成**
   すべてのアウトプットを統合した戦略分析レポートを作成する。

4. **ファイルに保存**
   `output/strategy-{YYYY-MM-DD}-{テーマ}.md` に保存する。

5. **ユーザーに報告**
   重要な洞察と推奨アクションをサマリーで報告する。

## 出力フォーマット

```markdown
# 戦略分析レポート：{テーマ}
作成日：{YYYY-MM-DD}

## エグゼクティブサマリー
（3〜5行で要点をまとめる）

## 核心問い
（問いの設計エージェントのアウトプット）

## 市場・競合分析
（市場調査エージェントのアウトプット）

## 戦略オプション
（戦略設計エージェントのアウトプット）

## リスク・課題
（批判的レビュアーのアウトプット）

## 推奨アクション
（優先度順に3〜5つ）
```
